# Plan of Action/Attack

When approaching this assignment, we suggest that you use this sequence. 
1. You should start at the `models` part of the assignment. 
2. Then move onto the `controllers` (DayCare).
3. Then move to Driver.

## 1. models
You should start here. We suggest that you work in this order: 

  - Write code for Pet.
  - Write code for Mammal.
  - Write code for Dog 
 
Test these classes using the given test classes. When these are fully passing, you can move on to the next step.

## 2. controllers

- Write code for addPet() and listPets().


## 3. Driver
- Write code for setting up minimal menu so that you can add and list (the added) dogs (pets).

Now you can see that your code is compiling and that the base functionality is working.

## 4. Finish the hierarchy 
- Finish the hierarchy and add the rest of the methods, writing the tests when necessary.
- Then change the driver code so that you can add one of each type of pet.

## 5. PetsDayCareAPI 
Examine the spec for the API - finish this as well as finishing the tests. 

## 6. Driver
- Finish Driver to incorporate all the functionality.

**As you work through each menu option, you should write the code in the Driver and write the body of the method in the controller that you need to call (replace the dummy code).  Your code should compile and produce the expected output before moving on to the next menu item**

 - Write dummy code for all methods (as per UML), this means write in the method headers and basic implementation to get the code compiled, at a later time you will write the implementation for each method.
- Write javadoc for this class. Remember, Javadoc code should describe what is being done, what is being returned, not how it is being done. It is like the instructions in a user-manual.


## Constraints
- You should not use library sorts (use algorithms given in class or similar)
- You should not use StringBuilder in your code

Using either of these will lead to a significant reduction in your mark.
