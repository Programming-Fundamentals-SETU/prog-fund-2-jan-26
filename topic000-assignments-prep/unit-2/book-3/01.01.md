# Overview

Your are tasked with developing a **Pet DayCare Management System** system.  It is a menu-driven, console app that can store pets of the following type:

- Dog
- Cat
- Parrot

The information entered via the app will be persisted in XML files.

# Starter Code
You will be given details on how to clone the starter code for this assignment, using GitHub Classroom. You should start from this code (it includes some code and tests) and build your solution on top of it.
You should regularly commit and push your work to GitHub.
You should use IntelliJ IDEA to develop your solution.

THe starter code is available at [GitHub CLassroom](https://classroom.github.com/a/Xm4mANuE).

(For more details on how to use GitHub Classroom, see last week's lab on GitHub Classroom - [here](https://tutors.dev/lab/prog-fund-2-jan-26/topic09-polymorphism-abstraction/unit-09b-labs/book-2-github). )


***Note***: You should select the test folder and mark it as **Excluded** - then when you are ready to start testing your code, you can select the test folder and mark it as **Test Source Folder**.

You will be provided with full UML for the classes in the **Pet DayCare Management System** system.  

From the coding perspective, you will be given a lot of starter code, with some classes fully completed and some partially completed.  You will need to fully code the inheritance hierarchy, the management of the collection of Pets, and the menu options for it.  More details on this later in the spec.
