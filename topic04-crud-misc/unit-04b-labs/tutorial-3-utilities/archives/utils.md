##  Utility Classes and Reusable Validation




## Exercise 1:  Design a Range Validation Method

You now want **one reusable method** that checks if a number is within a range.

👉 **Write a method that:**
- is `public` and `static`
- returns `boolean`
- takes **three parameters**:
  - number to check
  - minimum value
  - maximum value
- returns `true` only if the number is within range (inclusive)


---

## Exercise 2: Write a String Length Validator

👉 **Write a utility method that:**
- checks if a string is **no longer than a given maximum**
- returns a `boolean`
- does not modify the string

---

## Exercise 3: Write a String Truncation Method

Sometimes we want to **fix** bad input rather than reject it.

👉 **Write another utility method that:**
- takes a `String` and a maximum length
- returns:
  - the original string if it is short enough
  - a truncated version otherwise
