# Using GitHub Classroom


## What is GitHub Classroom?
GitHub Classroom is a tool built on top of GitHub that allows your lecturers to distribute, collect, and manage programming assignments at scale. When your lecturer creates an assignment, Classroom automatically generates a personal private repository for you when you accept the invite link, keeping everyone's work separate and organised. It removes the need to manually hand in code — your final push to your repository is your submission, and your lecturers can see your repository at any time.

We will  use GitHub Classroom area to manage the programming assignment for this module. 

When we hand out an assignment, we will give you an **invite link** to a specific assignment area in our GitHub Classroom.  

So that you are fully familar with how this GitHub Classroom works, we are giving out this lab for you to practice it in lab

## Main Steps for working on the formative assigment


In this formative assignment, you will perform the following steps (this lab take you through this approach in detail):


- You will be given an **invite link** to the assignment in our GitHub Classroom area.

- When you click on the link, you accept the assignment from our Github Classroom; this will create a new **remote repository** for you in our classroom area in GitHub.

- You will then **clone** this remote repo onto your **local machine (via IntelliJ)**.  This will setup a project in IntelliJ for you with starter code. 

- This starter project is **LabStarterCode**. 

- This starter project is a version of Social Network with a **TODO** instruction in the **MessagePostTest** in the test directory.

- You may have to update settings (e.g. mark test directory as test source root, import the xstream as a library - it is physically there etc) 

- As you complete the settup and complete the **TODO**, you should continually commit and push your changes to your remote repo.

- Your final push to your remote repo will be your submission.
